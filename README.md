# PyQt6 - Penjualan Pulsa

## Instalation

```bash

# Clone this project
git clone https://github.com/evanalifian/pyqt6-sapulsa.git

# Create python virtual environment
python -m venv env

# Start venv
.\env\Scripts\activate

# Install packages
pip install -r requirements.txt

# Start the app
python main.py
```
